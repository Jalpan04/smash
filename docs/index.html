CORE ARCHITECTURE

language

Offline NLP translation

Translate local queries (e.g. `smash list all python files`) to native system commands completely offline with an embedded T5-small model.

memory

Static GLIBC Compatibility

Engineered with low-level FFI C shims that intercept modern ISO C23 library calls and map them to legacy glibc entries, preventing dynamic symbol link errors on older Linux systems.

troubleshoot

Zero-Config Auto Detection

The shell dynamically inspects your home user profiles and fallback local folders to auto-resolve and load the neural model assets without environment variables.

terminal

Complete Shell Platform

Equipped with tab auto-completion, numbered shell history, custom startup rc configurations, platform-aware alias expansions, and background thread execution.

devices

Platform Agnostic

Designed as a single cross-platform codebase. Generates native PowerShell cmdlets on Windows and POSIX-compliant Bash pipelines on Linux.

build_circle

Built-In Utilities

Direct filesystem path navigation (`cd`, `cd -`, `pwd`), alias managers, clean session clear actions, and shell-level environmental assignments.

THE RUST PERFORMANCE MATRIX

By implementing the ONNX Runtime directly inside our Rust memory layout, Smash avoids high IPC context-switch costs. The shell operates with microsecond-level parsing pipelines and resolves transformer inputs locally, creating a fully sandboxed offline translation companion.

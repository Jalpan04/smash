CORE ADVANTAGES

AI Translation

Translate plain English into code: `smash list all python files` immediately runs the right command for your host OS.

True Offline Inference

Embedded fine-tuned T5-small model (~240 MB) running locally on your CPU. No API keys, no network calls, and sub-200ms latency.

GLIBC Backward Compatibility

Built with custom FFI shims targeting legacy standard C libraries, allowing static ONNX compilation to run flawlessly on Ubuntu 20.04+.

Smart Model Loading

Zero configuration. Smash automatically auto-detects and loads your local model directly from `~/.smash/model` without shell profile dependencies.

Full Shell Capability

Tab completion, persistent history, cross-platform aliases, environment variable expansion, and background processes.

Pure Rust Core

Engineered for extreme performance, minimal resource usage, and compile-time memory safety guarantees.

UNDER THE HOOD

Smash encapsulates a complex machine learning architecture into a zero-dependency system executable. During runtime, it uses the optimized Pyke ONNX system bindings to execute natural language translation on CPU threads using tokenizers and neural matrix math libraries in native speed.
